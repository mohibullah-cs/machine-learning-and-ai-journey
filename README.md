⚙️ Installation

Clone the repository:

git clone https://github.com/mohibullah-cs/machine-learning-and-ai-journey.git

Install dependencies:

pip install -r requirements.txt

For AI API projects, create a ".env" file and add your Groq API key:

GROQ_API_KEY=your_groq_api_key_here
GROQ_MODEL=openai/gpt-oss-20b
